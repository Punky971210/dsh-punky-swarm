# 项目 Constitution — video-team 治理原则

> 生成日期：2026-10-14
> 用途：本团队（video-team）项目级不可协商的治理原则，所有角色自动引用；**独立完整，不引用其他团队的宪法**

---

## I. 三层职责纪律

| 条目 | 类型 | 说明 |
|---|---|---|
| **C-01** | MUST | **plan 两步不可合并**：先摸底拆线（`coordinator`）⇒ 再逐线出包（`designer`）；摸底未出件不得出包 |
| **C-02** | MUST | **任务包是唯一验收单元**：包外追加要求一律回 plan 层补包 |
| **C-03** | MUST | **audit 只做逐条验收，不做二次评审**；未决项只进 `gap-list`，**不得以「继续调查」收尾** |
| **C-04** | MUST | **归档归 `supervisor`**（本团队**不设文档管理角色**，归档面不另立角色） |

---

## II. 写域互斥与并行划线

| 条目 | 类型 | 说明 |
|---|---|---|
| **C-05** | MUST | **写域互斥**：同一批次内任两 lane 的写域交集为**空**；有交集的活**必须**先拆线 |
| **C-06** | MUST | **并行划线由 `coordinator` 判定**，**不写死形态**；「每场一个 standalone HTML = 一个写域」仅为**历史实证形态参考** |
| **C-07** | MUST | **一个写域一个写者**：lane 只写自己的写域；跨域改动须**另开 lane** |
| **C-08** | MUST | **改动面证据一律路径限定**（`git status --porcelain -- <写域>`）；**禁**用全局工作树状态充当 lane 级证据 |

---

## III. 分段渲染纪律

| 条目 | 类型 | 说明 |
|---|---|---|
| **C-09** | MUST | **分段渲染**：每场先出 **standalone HTML**（可独立渲染/截图），再合成；**禁**一次性大文件堆积 |
| **C-10** | MUST | **场次 HTML 须 self-contained**（无外部相对依赖；素材以可解析路径引用并登记） |
| **C-11** | MUST | **动效须确定性可复现**（禁随机、禁时间依赖；seed/参数须落盘） |
| **C-12** | MUST | **帧级自查**：新增/重设计帧后须跑 `frame-occlusion-audit`；⚠ **error 计数不可跨采样密度比较**，判据主体 = **相交对的身份集合** |

---

## IV. 宿主冒烟 DoD

| 条目 | 类型 | 说明 |
|---|---|---|
| **C-13** | MUST | 完成判据须含**一次真实加载/启动冒烟**；`node --check` / 单测**不算**完成 |
| **C-14** | MUST | **RED→GREEN 作中间 checkpoint**：先搭会失败的版本，再做到通过；**禁攒批到终验** |
| **C-15** | MUST | 冒烟须**指向具体消费路径**（宿主/加载链路），并留**原始回显** |
| **C-16** | MUST | 未验证须写「未验证」；**不得**以「应该能跑」代替读数 |

---

## V. 素材许可与版权

| 条目 | 类型 | 说明 |
|---|---|---|
| **C-17** | MUST | **四类素材来源全登记**：BGM / 字体 / 图像 / 配音 —— 逐项给**来源 + 许可** |
| **C-18** | MUST | **不得使用许可不明的素材**；商用受限素材须在登记表标注限制 |
| **C-19** | MUST | **配音合成可复现**（固定 seed / 参数落盘）；**不得**使用未授权的人声克隆 |
| **C-20** | SHOULD | 引用第三方素材须保留**出处**（同一登记表内可查） |

---

## VI. 字幕 / 气口 / 成片验收 / 缺陷回退

| 条目 | 类型 | 说明 |
|---|---|---|
| **C-21** | MUST | **字幕与配音时间轴对齐**；对齐误差须在包内声明阈值内 |
| **C-22** | MUST | **气口口径**：按呼吸组识别，**整组压缩**；判据未成立时**只报不裁**；裁剪**逐组留痕** |
| **C-23** | MUST | **成片验收口径**：按任务包 `## 验收标准` **逐条核对 + 独立复现**；**⚠「导出」不属团队工序**（**导出是成片之后的工序**）⇒ **不得**把导出当验收项 |
| **C-24** | MUST | **缺陷与回退**：`supervisor` **只读不改码**（缺陷走报告）；**修复走新批次**；回退按「弃实现、保思路」低成本重来 |

---

> **独立完整性**：本文件**自含完整** —— 不引用、不依赖其他团队的宪法或校验脚本；本团队的角色名、层级与判据**均在本文件内定义**（角色清单见 `roles/`，逐字为 `coordinator` / `designer` / `producer` / `captioner` / `motion-designer` / `audio-engineer` / `supervisor`，共 **7** 个，无第 8 个）。
