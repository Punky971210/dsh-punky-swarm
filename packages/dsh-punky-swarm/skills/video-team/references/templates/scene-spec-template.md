# 场次规格模板（designer 出包用）

> **用法**：把本件复制为 `plan/<name>-spec.md` 后**逐格填写**；每节下方的「填法」是该格的**形态要求**与**合格长相**，写完可自删。
> ⚠ **本模板是「填空即用」的空表，不是范例正文**：所有 `<>` 都是必须替换的占位。
> ⚠ 与任务包的关系：本件产出的是**场次规格**（判据源）；面向 exec 的**单场任务包**另出 `plan/<name>-taskpack-<n>.md`（8 段结构，按 `spec-writing`）。

---

## 场次目标

| 格 | 填什么 | 合格长相 |
|---|---|---|
| 场次 id | `<scene-id>`，小写连字符 | 与任务包文件名、产物目录名**逐字一致** |
| 一句话目标 | 这场要**让观众看到什么** | 一句、可判、不含「做好看些」这类不可判词 |
| 在成片中的位置 | `<第 n 场 / 共 m 场>`、前接 `<scene-id>`、后接 `<scene-id>` | 前接/后接**必须**是已存在的场次 id（首场写「无」） |
| 时长预算 | `<目标秒数 ± 容差>` | 给**容差**；无容差的时长不可验收 |

## 时间轴

| 段号 | 起止（秒） | 内容 | 承担角色 |
|---|---|---|---|
| `<T-01>` | `<0.0 – 3.5>` | `<该段发生的画面/解说/字幕事件>` | `<producer / captioner / motion-designer / audio-engineer>` |

> **填法**：段号 `T-NN` 连续无跳号；**段时长之和必须等于**「场次目标」的时长预算（± 容差内）。
> **合格长相**：任一段都能被 quote 出「起止 + 内容 + 角色」三要素，且**相邻段起止首尾相接**（无空洞、无重叠）。

## 素材清单

| 素材 id | 类型 | 来源 | 许可 | 落盘路径（相对批次产物根） |
|---|---|---|---|---|
| `<M-01>` | `<图 / 视频 / 音频 / 字体 / 图标>` | `<自产 / 采集路径 / 生成命令>` | `<见素材许可登记表>` | `exec/<lane>/assets/<name>` |

> **填法**：**许可列必填**，不得留空、不得写「待定」。
> **合格长相**：每个素材有一行；**许可**能对应到 workflow 的「素材许可登记」口径（自产 / 授权 / 公有领域 / 生成式产出）；未确权的素材**不得**进入本表（改走 gap-list）。

## 字幕与气口口径

| 格 | 填什么 | 合格长相 |
|---|---|---|
| 字幕语言与风格 | `<中文 / 中英对照>`、`<逐句 / 关键词>` | 与 `captioner` 的产物契约一致 |
| 气口处置 | `<按呼吸组识别，整组压缩到 N 秒>` | 明写**整组压缩**（不逐峰裁）；明写**判据未成立时只报不裁** |
| 裁剪留痕 | `<逐组留痕路径>` | 给**逐组**留痕的落盘路径（不是汇总一份） |
| 可疑段处置 | `<标注后交 supervisor 裁决>` | 不得静默丢弃 |

## 验收标准

> **本节是 audit 的判据源锚点**：裸标题行不得改写层级、不得加粗、不得加编号前缀。

| ID | 判据（**带限定量词**） | 通过条件 | 读数形态（原始回显） |
|---|---|---|---|
| `<AC-1>` | `<例：帧内不出现元素遮盖 ⇒ text_occluded 相交对数 = 0>` | `<可判条件>` | `<命令原文 + 输出原文>` |
| `<AC-2>` | `<例：时长落在 12.0 ± 0.5 秒内>` | `<可判条件>` | `<读数原值>` |

> **填法**：每条判据**必须带限定量词**（数值/集合/计数/存在性）；**禁裸「零命中」**——须写成「**`<某个具体集合或命令的输出>`** 的 `<某个具体串>` 命中数 = 0」。
> **合格长相**：每条都能被一个命令或一次目视复现成读数；**可达反例**（该判据真能报错的情形）至少给一条。

## 预算行

```
预算：W ≈ <n>M（C≈232K × T≈<轮次>）；切法：<①…②…③…>；每步落一次 progress 快照，禁攒批。
```

> **填法**：`n` 取值 4–10；`切法` 列**可独立交付的子步骤**（而非「先想、再想、然后做」）。
> **合格长相**：切法的每一步都能单独落一份 `<lane>/progress/NN-<slug>.md`。
