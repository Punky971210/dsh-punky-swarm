# 端点行为定义模板

> 本文档定义前端端点和 API 端点的行为规范，作为 spec.md 的组成部分。
> Designer 在产出四件套时，必须为每个受影响的端点填充此模板。

---

## 端点行为明细表

| 端点 ID | 类型 | 路径/标识 | 方法/事件 | 触发条件 | 输入 | 输出/响应 | 错误码 | UI 影响 |
|---------|------|-----------|----------|---------|------|----------|--------|---------|
| EP-01 | API | `/api/v1/xxx` | POST | 用户点击提交按钮 | `{请求体结构}` | `{响应体结构}` | 400/404/500 | 提交按钮进入 loading → 成功跳转页面 / 失败显示错误提示 |
| EP-02 | 前端事件 | `PageX.submitBtn.onClick` | 点击事件 | 表单填写完整后点击 | `{表单字段}` | 调用 API → 更新本地状态 → 路由跳转 | N/A | 按钮 disable + spinner → 页面对比更新 / Toast 提示 |

### 字段说明

| 字段 | 说明 |
|------|------|
| **端点 ID** | 全局唯一标识，格式 `EP-{序号}`，供 coder-tasks/tester-tasks 引用 |
| **类型** | `API`（HTTP 端点）或 `前端事件`（组件事件） |
| **路径/标识** | API 端点为 URL 路径；前端事件为 `Page.Component.Event` 格式 |
| **方法/事件** | API 端点为 HTTP Method；前端事件为 DOM 事件类型 |
| **触发条件** | 该端点被调用的前置条件 |
| **输入** | API 端点为请求体 JSON Schema；前端事件为事件载荷的数据结构 |
| **输出/响应** | API 端点为响应体 JSON Schema；前端事件为调用后的状态变更/副作用 |
| **错误码** | API 端点的 HTTP 状态码及含义；前端事件为异常状态的处理方式 |
| **UI 影响** | 该端点执行后前端 UI 的预期变化（加载态/成功态/错误态/跳转） |

## 端点依赖关系

| 端点 ID | 依赖的端点 | 依赖类型 | 说明 |
|---------|-----------|---------|------|
| EP-01 | EP-02 | 先决 | EP-02 完成后 EP-01 才能获取到所需数据 |
| EP-03 | — | 独立 | 无依赖，可独立开发和测试 |

### 依赖类型

| 类型 | 含义 |
|------|------|
| **先决** | 本端点依赖目标端点先执行完成 |
| **数据** | 本端点依赖目标端点产生的数据 |
| **并行** | 两个端点无依赖，可并行开发和测试 |
| **互斥** | 两个端点不能同时触发 |

## 端点级验收标准

每个端点必须满足以下验收标准：

```
[EP-XX] 验收标准
- [ ] 输入校验：无效输入返回正确错误码/错误状态
- [ ] 正常流程：合法输入返回预期输出/预期 UI 变更
- [ ] 边界条件：[具体边界值] 时行为正确
- [ ] 错误处理：超时/网络异常/服务不可用时的降级表现
- [ ] UI 一致性：成功/失败/加载三种状态 UI 表现符合设计稿
```
