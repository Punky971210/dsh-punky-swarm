## §0 判定口径（本次确立，属规范）

| 判据 | 内容 |
|---|---|
| **冗余检查的定义** | 某守卫/断言所防御的状态，在**结构上不可能构造** ⇒ 该检查是「为不可能发生的状态加禁止性断言」，属冗余 |
| **正解** | **用结构性保证取代禁止性断言**——让引擎**不提供**产生该状态的回路（如：deps 只许指向既有任务 ⇒ 不可能成环） |
| **反例（不算冗余）** | 状态**可由调用方输入构造**（如用户写错 deps 指向不存在 id）⇒ 必须拦 |
| **与既有纪律的关系** | 与 R3g 的「不可达 ⇒ 只登记 + 绊线」同旨；与判据分层通则（fail-closed / fail-open / 条件未成立）互补——本次新增第四型：**结构性不可能（应删，不是登记）** |

**可复用的先例**：`wave-plan.ts:738-742`（G-08）判定旧 audit 配对判据为「零可达性的空转校验」，理由正是「要满足即须自指环，而自指环先被 topoWaves 拒绝」⇒ 项目内**早已有**「空转校验」概念，但**没有系统性清查**。

## §1 清查方法与覆盖声明

**手段**（三种识别路径，可复核）：

1. **显式自述型**：`lib/**` 全文 grep 关键词（恒 false / 恒 true / 不可满足 / 空转 / 零可达 / 不可达 / 永不命中 / 不可能 / 死码 / 冗余）⇒ **66 条命中**，人工逐条分类。
2. **结构型**：迁移表边 × 实际调用点比对（`MEMBER_TRANSITIONS` vs `setMember` 的 `to` 值集合）。
3. **既有盘点复用**：`scripts/audit/dead-code2.mjs`（导出符号死码）、门禁台账（断言覆盖）、R3g 台账（无断言 2 枚）。

**⚠ 覆盖声明（必须写明）**：本项目**没有**针对「守卫可达性」的系统性审计手段——
- `dead-code2.mjs` 扫的是**导出符号**死码（A/B/C 类），**不覆盖**守卫/分支可达性；
- 门禁台账只做「**断言覆盖**」判定（无断言 2 枚），**不做可达性**（R3 教训：有断言 ≠ 可达）；
- ⇒ 本次只能保证「**自述型 + 结构型**」被查出；**未自述的遮蔽型**（被更严一层前置拦截而静默失效）**可能仍有遗漏**，需专项审计（见 §3）。

### 2.1a ⚠ 判读更正：`assets.js` 的 `target.escape` 防御**不是冗余**（不得删）

- **原判定**（一轮）：依注释「schema 路径规则已使其不可达…单测直调覆盖」⇒ 归入冗余待裁。
- **实证推翻**（二轮）：`resolveTarget(home, target)` 是 **export 函数**，**自身不校验入参**（`isValidRelPath` 在别处 `:139` 做）。⇒ 调用方/直调**可以**传入 `{ subpath: '../../escape' }`。
- **反例就在测试里**：`test/assets.test.js:248-250` 直接构造了逃逸 subpath 并断言 `escaped.reason === 'target.escape'` ⇒ **状态可构造**。
- ⇒ 按口径「输入可构造 ⇒ 必须拦」⇒ 归 **③，保留**。
- **教训（与 R3 同族）**：**注释自述的「不可达」不能当判据**——「宣称为真 ≠ 实现为真」。判④必须用「能否构造出该状态」的实证，不能用注释。

### 2.1b 新发现（2026-09-21 二轮）：**退役码的注释残留**（第 5 类）

`GATE_MANAGER_TERMINAL` · `GATE_MANAGER_PHASE_INVALID` · `GATE_MANAGER_AGENT_ID_REQUIRED` · `GATE_MANAGER_NOT_RAISED` · `GATE_TEAM_ASSET_MISSING`

- 码**已删**（注释逐字「三码已删」「硬门已删」），但注释/文档仍在引用 ⇒ grep 会把它们当成**活着的守卫**。
- 与 R3 的「说已防护、实未防护」同族、方向相反：**说已删除、却被当活码**。
- **不是冗余检查**（没有检查代码可删），是**判读污染**。
- **处置（2026-09-21 已执行）**：注释**保留**（退役理由有价值），在 3 处加统一标记 **`【已退役码·勿引用】`**（`store.js:1028` 三码 / `gates.ts:838` / `flows.js:124`），使人工与 grep 一眼可辨；扫描器 `--classify` 已能自动归入 `retired` 桶。
  ⚠ 为什么不是「字面删除」：删掉会丢失「为什么退役」的历史依据；污染来自**误读**，加标记即可消除。若你要求字面删除，再说一声。
